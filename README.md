In this task, I created a tabbed interface with three tabs: Home, About, and Contact.
When a tab is clicked, its related content is shown and the other content is hidden.
In the main method, I used `display: block` to show content and display: none to hide it.
In The Test, I learned three ways to create tabs: using display toggle, using the hidden attribute, and removing elements from the DOM with remove() and adding them again with appendChild().
The display method keeps all elements in the DOM, the hidden method hides them, and the remove method takes elements out of the DOM.
In the Challenge, I used classList.add() and classList.remove() to add an active class to the selected tab and remove it from the other tabs.
This helps highlight which tab is currently active.
